# SubShelf（サブスクリプション棚卸しアプリ）

手入力前提で続けやすい、個人向けサブスク棚卸しPWAです。

## 機能
- 追加（必須: サービス名/金額/頻度/次回請求日）
- 一覧（検索、ソート、フィルタ）
- ホーム（今週の請求予定、期限超過の一括処理）
- ダッシュボード（月額換算/年額換算、カテゴリ別、Top10）
- ローカル永続化（IndexedDB）
- JSONバックアップ・復元 / CSVエクスポート
- PWA対応（ホーム画面追加）

## ローカル起動方法
依存パッケージ不要です。静的サーバーで起動してください。

```bash
python3 -m http.server 4173
```

ブラウザで `http://localhost:4173` を開きます。

## 使い方（主要フロー）
1. **追加**: 「追加」タブから登録（頻度選択で次回請求日を自動提案）。
2. **請求処理**: 一覧 or ホームで「請求済み」を押すと次回請求日が1周期進みます。
3. **週1棚卸し**: ホームの「期限超過」で「一括処理」を押し、請求済/停止/金額変更を順に処理。

## バックアップ方法
- **JSONバックアップ**: 「データ」タブの `JSONバックアップ` を押すと全件を保存。
- **JSON復元**: `JSON復元` でバックアップファイルを選択（既存データは置換）。
- **CSVエクスポート**: 「データ」タブの `CSVエクスポート` から表計算向けに出力。

## データ仕様（保存）
IndexedDB `subshelf-db / subscriptions` に保存。
主要フィールド: `serviceName`, `amount`, `frequency`, `nextBillingDate`, `category`, `paymentMethod`, `tags`, `memo`, `autoRenew`, `status`。
